# Blinkit Sales Analysis Dashboard

## About the Project

This project focuses on analyzing Blinkit's sales data to understand product performance, sales trends, and outlet characteristics. I used SQL, Python, Microsoft Excel, and Power BI to analyze the data and build an interactive dashboard that presents useful business insights.

The main objective was to explore sales across different product categories and outlets, identify performance patterns, and make the data easier to understand through visualizations.

## Tools & Technologies

- **SQL:** Querying, filtering, and analyzing sales data.
- **Python:** Data cleaning, preprocessing, and exploratory data analysis.
- **Microsoft Excel:** Data organization, validation, and preliminary analysis.
- **Power BI:** Creating interactive dashboards, visualizations, and key performance indicators.

## Key Performance Indicators (KPIs)

The dashboard includes the following metrics:

- **Total Sales:** Overall sales value.
- **Average Sales:** Average sales value.
- **Number of Items:** Number of items represented in the analysis.
- **Average Rating:** Average customer rating.

## Analysis Performed

In this project, I explored different aspects of Blinkit's sales data, including:

- Sales performance across different item categories.
- Sales distribution by item fat content.
- Comparison of outlet types and outlet sizes.
- Sales across different outlet location tiers.
- Outlet establishment year and its relationship to performance.
- Item visibility and customer ratings.

These analyses help understand how product categories and outlet characteristics relate to overall sales performance.
